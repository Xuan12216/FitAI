# 2026-10-25 Gemini 改動修正與驗收

## 修正內容

- 移除五家網路 AI 的假引用補入邏輯。沒有實際引用的數值不會通過解析，也不會標成食藥署資料。
- FatSecret 必須保留餐點配料與品牌匹配，不再以單一重疊字接受其他餐點，也不再將查詢詞寫成任意候選的別名。保留常見繁簡字形比對。
- 沒有明確重量時保留每份／每個等原始基準；有明確重量才能換算每 100 克。拒絕模糊份量與重量區間。
- 表單準備階段最多 8 秒，送出後另有完整 30 秒回答時間。整輪上限涵蓋三家各自的準備與回答時間。
- 自動查詢與使用者再次查詢皆可輪替最多三家不同 AI；逾時、一般網路錯誤或不完整回答可切換，且顯示目前來源與輪次。
- 真人驗證、HTTP 403/429 等存取限制會立即停止本輪，不當成普通連線錯誤繼續輪詢。
- 不猜測模型名稱；讀不到時標示平台與「模型未知」。首頁、手動表單、掃描結果都保留本地 Gemma 估算歸屬。
- 餐別改為圖示、主要色標題與分組總計；餐點使用縮排卡片。維持超過三筆自動收合與手動展開／收合。
- 手動重試整輪失敗或逾時時，保留原有數值與來源，並正確提示未更新；不宣稱已啟動本地重估。

## 驗證結果

- `testDebugUnitTest`：129 項通過，無失敗、錯誤或略過。
- 正式套件 `assembleDebug`：成功。
- SM-F9710 的獨立套件 `com.xuan.fitai.probe`：12 項本地 WebView／Compose 回歸測試通過。
- 唯一一次真實網路輪替測試：Google 約 30.1 秒仍沒有可用引用，自動切換 Gemini；Gemini 約 6.1 秒提供可解析答案及一筆引用。頁面讀到的模型名稱為 `Gemini 3.5 Flash-Lite`，共查詢兩家，測試通過。
- `git diff --check` 通過；檢閱修正後的計時、取消清理、失敗輪替、來源標示與份量換算，未發現新的阻擋問題。

- 保留工作區原有 Gemini UI 改動，未重置或提交其他修改。
- 修正驗收階段使用獨立測試套件，未覆寫正式 FitAI 或其餐點資料；後續依使用者要求安裝 release，結果如下。
- 實機截圖為測試餐點資料；未驗證所有外部 AI 在所有時段都能使用，也未做封鎖門檻壓測。
- 真實網路測試後僅補強本地份量區間拒絕、共用逾時檢查與手動逾時提示；未追加網路提問。最後原始碼重新通過單元測試及 Debug 編譯。
