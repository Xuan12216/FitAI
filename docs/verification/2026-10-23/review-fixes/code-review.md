# FitAI 1.3.1 — Gemini Review 問題修正

## 完成內容

保留 Gemini 的首頁、體重圖、訓練計時及 ModalBottomSheet 改版。本次由實作者檢查與修正，沒有獨立外部審查者。

1. 未提供質量的每份資料不再轉成每 100g：網頁只接受來源明確標示克數的數值，不推算重量，不將 ml 當成 g。內建 6 筆只有毫升基準的飲品範例移除，由可用網路／官方資料或本地估算處理。
2. 清理內建資料的錯誤別名：魚堡與雞腿堡、低脂與全脂、無糖與微糖、海帶與豆干，以及不同餡料、烹調方式不再互相當同義詞。保留 66 筆近似配方，提示詞與來源明細皆明示非官方／品牌營養標示。
3. 網頁比對保留完整名稱、配料、品牌及修飾詞；取消任意兩字重疊與反向縮短餐點的接受方式，排除調味醬、湯底、麵粉等與查詢不同的食品型態。保留「章魚燒／章魚小丸子」等明確同義詞。括號重排不再忽略括號後的配料；熟食查詢不再移除烹調前綴後直接套用生肉數值。
4. 新增共用 AdaptiveModalBottomSheet，四個表單都沿用 Material 的遮罩、拖曳與動畫。分隔摺痕時依實際視窗和鍵盤可見高度選擇單一 pane；姿勢改變重排位置並保留輸入，遮罩仍覆蓋整個視窗。

## 一併修正的來源與備援問題

- 保存來源實際項目 URL，明細可開啟該筆原始頁；只允許已知營養網站的 HTTPS URL，備份匯入也驗證。
- 內建近似配方不再提供食藥署連結當作逐筆出處；近似資料的程式換算說明也保留不確定性標示。
- 網頁快取限制 24 小時，重用資料時保留真正取得時間；TFDA 的下載時間與快取狀態不再被現在時間覆蓋。
- 網頁階段最多約 3 秒，TFDA 下載／解析階段最多 16 秒，仍保留 FoodAssessment 的整體 20 秒回退。若已有合適內建配方，網頁失敗後不再額外等待整份 TFDA 下載。
- 原先設定的 TFDA 12 秒預算在隔離模擬器可重現不足：單獨解析約 12.3 秒，建置重疊時約 16.4 秒。依此重新分配查詢時間，沒有放寬既有原始資料解析測試的 15 秒門檻。

## 限制與資料處理

查無明確重量或名稱不符的來源會略過，可能降低命中率，改用本地估算。內建配方只是近似範例；即使程式正確換算克數，實際餐點的配料與製法仍須確認。歷史餐點數值不會被不具可靠出處的推測自動覆寫，需要重新評估後儲存才會更新。
