# FitAI 1.3.2：台灣營養來源與餐點分組

## 變更

- 新查詢完全移除 FatSecret 中國站的網路請求。餐點依類型讀取臺大膳食協調委員會的早餐、麵食、飯類、點心或湯類熱量表；一般食材繼續使用衛福部食藥署 TFDA 資料。未找到合適來源時才使用已標示的內建近似配方／本地 AI 估算。
- 重現火腿蛋餅漏失：中國站原始頁回傳火腿蛋堡、三明治等不同食品，不能作為蛋餅的數值。臺大早餐表提供相符餐點。本版保留來源每份熱量，不再因未提供克重而整筆略過。
- 營養資料新增份量基準與三大營養素是否公布的 metadata。提示詞、來源明細、程式換算、JSON 備份皆使用相同基準。沒有克重時不換算每 100g；未提供營養素時顯示「未提供」，保留 AI 估算而不寫成來源數值 0。
- 來源頁採完整餐點名稱比對，保留品牌、糖分與配料；只移除來源中英文對照的英文名稱。薄／厚兩組熱量等無法確定的資料不擅自選值。每次最多請求一個已知台灣頁面，不遍歷外部連結；維持 3 秒網頁階段與既有整體逾時回退。
- 新增餐點預設依記錄時間帶入：05:00–10:59 早餐、11:00–16:59 午餐、17:00–21:59 晚餐，其餘宵夜。手動表單修改時間時自動更新餐別；手動指定後保留選擇，可一鍵恢復自動。照片及對話存入餐點也使用同一時間規則。
- 「再記一次」與常用餐點套用這次的記錄時間；編輯原有紀錄保留原餐別，歷史資料不自動改寫。
- 今日及歷史餐點依餐別固定排序。每組 1–3 筆預設展開，超過 3 筆預設收合，摘要顯示筆數、熱量、蛋白質／碳水／脂肪合計與前三個名稱；可點擊展開或收合。展開狀態與筆數無關，使用者手動選擇優先；刪除／編輯／再記一次仍於展開後操作。

## 複查

由實作者自行檢查，未使用獨立審查者。檢查重點為新來源的單位、未知營養素、舊 JSON 相容性、來源 URL、時間邊界、手動餐別覆寫與收合前後合計一致。

舊營養 JSON 未含新欄位時仍按舊版每 100g／完整營養素解讀，避免改變歷史數字。舊 FatSecret 來源連結保留可讀性，但本版不再向中國站發送新查詢。Room schema 不變，沒有清除或還原手機資料。

公開餐點表不是每家早餐店的品牌標示，也沒有每筆克重與三大營養素。份量與配方仍可能不同，缺少的營養素仍須估算。只支援已接入且能明確比對的資料，不保證所有台灣餐點都查得到。這版不包含前一輪尚未要求執行的草稿保護、固定儲存列等建議。
