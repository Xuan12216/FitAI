# 快速回答調整：1.3.6（10）

## 變更

- Google AI、Brave AI、Duck.ai 共用短提示：繁體中文、快速查詢四項營養、優先一個完整資料來源（台灣優先）、不足時最多兩個，不深入研究或比較；僅回一列資料和一個完整來源網址。缺值明說，不要求模型編造。
- 初版「僅一個台灣來源」在實機找到只有熱量的頁面，Google／Duck.ai 因缺少營養值而被拒收。因此放寬來源數量，保留原有餐點、份量、四項營養值及引用檢查。
- Duck.ai 在送出前透過公開 UI 明確選「快速」並開啟網頁搜尋。手機診斷確認 fast=true；桌面檢查原先已顯示快速選中，因此不能將之前的慢全部歸因於推理模式。
- Duck.ai 的本機操作選單與填表階段，檢查間隔從 650ms 改為 150ms；送出後仍為 650ms。此間隔調整不會追加提問或重新送出表單。
- 本地 Gemma 的營養提示要求快速實用估算、不要深入分析，建議及份量假設各用一句；保留原 JSON 欄位及份量規則。不修改使用者已保存的 thinking 設定或重新載入模型。
- 回答的數值穩定檢查（連續三次）、每來源 25 秒期限、單次手動／三次合計提問上限、來源輪替及驗證停止規則均維持。

提示不能保證遠端服務的內部思考量或回應時間；Duck.ai 的 fast=true 代表已選公開 UI 的快速選項。網路、排隊、搜尋及來源完整度仍會影響耗時。
